# UNAMA Cypress

Aplicação web acadêmica com testes automatizados end-to-end usando Cypress.

## Objetivo

Demonstrar a criação e execução de testes automatizados para uma aplicação web com páginas de login e conteúdo estático.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Cypress

## Como executar

Instale as dependências:

```bash
npm install
```

Abra o Cypress em modo interativo:

```bash
npx cypress open
```

Ou execute os testes em modo headless:

```bash
npx cypress run
```

## Observação

`node_modules` não faz parte do repositório. As dependências devem ser instaladas com `npm install`.
